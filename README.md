
📝 calculo planificação peça curva

Uma aplicação web simples e intuitiva para calcular e gerar a planificação de peças de MDF em formato 2D. O usuário informa a largura e o raio da peça, o sistema realiza o cálculo estrutural automaticamente, exibe o desenho técnico planificado na tela e permite a exportação da imagem gerada.

🚀 Funcionalidades

• Cálculo Automatizado: Processa instantaneamente a planificação com base na largura e no raio digitados.
• Visualização 2D: Desenha em tempo real o formato da peça final utilizando recursos nativos da web.
• Exportação de Imagem: Permite baixar a imagem 2D gerada (em formato PNG/SVG) com apenas um clique.
• Interface Responsiva: Design limpo e adaptável para uso em computadores, tablets ou smartphones.

🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido de forma 100% nativa, sem a necessidade de instalar frameworks ou bibliotecas pesadas:
• HTML5: Estruturação semântica da aplicação e dos formulários.
• CSS3: Estilização moderna, layout responsivo e transições suaves.
• JavaScript (Vanilla): Lógica dos cálculos matemáticos, manipulação do DOM e renderização do desenho técnico (via Canvas ou SVG).

💻 Como Executar o Projeto

Por se tratar de uma aplicação estática (front-end puramente), você não precisa instalar nenhuma dependência ou rodar servidores complexos.
1. Faça o clone deste repositório:bash

Use o código com cuidado.
2. Navegue até a pasta do projeto:bash
cd seu-repositorio
Use o código com cuidado.
3. Abra o arquivo index.html diretamente no seu navegador de preferência.
